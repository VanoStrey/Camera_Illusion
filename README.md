# 🎥 Camera Illusion

> Реал-тайм версия эффекта «зрение только через движение»: веб-камера → иллюзия, в которой видны только движущиеся объекты, а всё неподвижное растворяется в цветном шуме.

## ✨ Что это

Программа открывает камеру, в реальном времени считает оптический поток (Farneback) и вместо
видео показывает **статическую 16-цветную текстуру-шум**, которую сдвигает `remap`-ом в сторону,
**обратную** движению сцены.

Работает классический эффект **motion-only vision**:

* 🚶 движущиеся объекты «проявляются» из шума;
* 🧱 неподвижный фон сливается в рябь и исчезает;
* 🎨 ни контуров, ни силуэтов — только движение.

Это «живой» аналог телеграм-бота
[Rust_VideoTlusia_bot](https://github.com/VanoStrey/Rust_VideoTlusia_bot): тот же алгоритм,
но без Telegram — камера и окно на экране, никаких файлов на диске.

| 🎛 Настройка | Размеры буферов выводятся из фактического размера кадра |

## 🧠 Как это работает (конвейер)

```
камера → кадр (BGR) → уменьшение → квантование → grayscale → Farneback flow
       → remap текстуры шума → увеличение (nearest) → BGR→0RGB → окно minifb
```

По шагам (`src/main.rs`):

1. **Открытие камеры**: `VideoCapture::new(0, CAP_AVFOUNDATION)`, запрашивается 1920×1080 @ 30 fps.
2. **Первый кадр**: до 300 попыток чтения с паузой 10 мс, пока кадр не станет непустым.
3. **Базовые размеры**: `small = кадр / PIXEL_BLOCK_SIZE` (÷4), `flow = small / 4` (итого ÷16).
4. **Инициализация**: текстура шума `generate_noise()`, сетки координат `grid_x`, `grid_y` (CV_32F).
5. **Каждый кадр**:
   1. уменьшение кадра до `small`, **квантование цвета** до `COLOR_LEVELS` уровней;
   2. grayscale → уменьшение до `flow`, **оптический поток Farneback** (Gaussian) к прошлому кадру;
   3. поток апскейлится до `small` и умножается на 4 (компенсация уменьшения);
   4. `map = grid − flow`; в неподвижных областях (`magnitude < 0.05`) карта сбрасывается на `grid`,
      то есть шум там не сдвигается вообще;
   5. `remap` базовой текстуры с `INTER_NEAREST` и `BORDER_WRAP` — текстура «уезжает» против движения;
   6. nearest-увеличение результата до исходного разрешения кадра;
   7. конвертация BGR `Mat` → буфер `0RGB` (`u32`) и вывод в окно `minifb`.
6. **Статистика**: раз в секунду `FPS: … (… µs/frame)`, счётчики сбрасываются.

## 🛠 Стек

| Компонент | Роль |
| --- | --- |
| [OpenCV](https://opencv.org/) 4.x (`opencv` crate 0.98) | Захват камеры, `resize`, `cvt_color`, `calc_optical_flow_farneback`, `remap` |
| [minifb](https://github.com/emilk/minifb) 0.27 | Кросс-платформенное окно и вывод кадра из `Vec<u32>` |
| `rand`, `lazy_static`, `bytemuck` | Палитра и генерация текстуры шума |
| `anyhow` | Ошибки с контекстом (`Context`, `bail!`) |

> `opencv` собран **без** feature `highgui` — окно рисует `minifb`, поэтому GUI-модуль OpenCV не нужен.

## 📋 Требования

* **Rust** 1.75+ (edition 2021) и `cargo`
* **OpenCV 4.x** с заголовками и `pkg-config`/`clang`
* **Камера**, доступная системе (на macOS — разрешение для терминала/IDE в *Настройки → Конфиденциальность → Камера*)

### macOS (Homebrew)

```bash
brew install opencv pkg-config llvm
```

### Debian / Ubuntu

```bash
sudo apt update
sudo apt install -y build-essential pkg-config libopencv-dev clang libclang-dev \
                    libxkbcommon-dev libwayland-dev libx11-dev
```

## ⚙️ Сборка и запуск

```bash
git clone git@github.com:VanoStrey/Camera_Illusion.git
cd Camera_Illusion
cargo run --release
```

Для нормального FPS нужен **release-профиль**: в debug поток Farneback на 1920×1080 не успевает
за камерой.

Пример вывода в консоли:

```
Камера открыта, ждём первый кадр...
Камера готова, размер 1920x1080
FPS: 29.8 (33550 µs/frame)
FPS: 30.1 (33210 µs/frame)
```

## 🗂 Структура проекта

```
Camera_Illusion/
├── Cargo.toml          # зависимости: opencv (без highgui), minifb, anyhow, rand, lazy_static, bytemuck
├── Cargo.lock          # зафиксированные версии зависимостей
├── .gitignore          # /target/, .DS_Store и системные артефакты
└── src/
    ├── main.rs         # камера, главный цикл, окно minifb, FPS-статистика
    ├── config.rs       # константы обработки
    ├── noise.rs        # генерация статической 16-цветной текстуры
    └── frame_utils.rs  # квантование цвета + вспомогательные функции прошлой версии
```

| Файл | Что делает |
| --- | --- |
| `main.rs` | Открывает камеру, ждёт первый кадр, крутит главный цикл, конвертирует `Mat` → `Vec<u32>` |
| `config.rs` | `PIXEL_BLOCK_SIZE`, `OUTPUT_SIZE`, `COLOR_LEVELS`, `MAX_DURATION_SEC`, `MAX_FILE_SIZE` |
| `noise.rs` | `generate_noise()` + палитра `NOISE_PALETTE` (16 цветов) |
| `frame_utils.rs` | `quantize_frame()`; `preprocess_frame`, `shift_texture`, `enforce_noise_rule` сохранены из видео-версии |

## 🔧 Параметры (`src/config.rs`)

| Константа | Значение | Где используется | Смысл |
| --- | --- | --- | --- |
| `PIXEL_BLOCK_SIZE` | `4` | `main.rs` | Во сколько раз уменьшается кадр для текстуры шума |
| `COLOR_LEVELS` | `4` | `main.rs` | Уровни квантования цвета перед потоком |
| `OUTPUT_SIZE` | `640` | — | Наследие видео-версии |
| `MAX_DURATION_SEC` | `60` | — | Наследие видео-версии |
| `MAX_FILE_SIZE` | `50 МБ` | — | Наследие видео-версии |

Зашито прямо в `main.rs`: индекс камеры `0`, разрешение `1920×1080 @ 30`, параметры Farneback
(`0.9, 1, 5, 1, 5, 1.1`, Gaussian), порог «неподвижности» `0.05`.

### Что легко изменить

| Задача | Где править |
| --- | --- |
| Другая камера | `let cam_index = 0;` в `main.rs` (`1` — вторая камера; в отладочном сообщении `cam_index` тоже учтён) |
| Другое разрешение | `CAP_PROP_FRAME_WIDTH/HEIGHT/FPS` в `main.rs` |
| Крупнее/мельче «пиксель-блок» | `PIXEL_BLOCK_SIZE` в `config.rs` (больше → грубее картинка, быстрее) |
| Больше оттенков в шуме | `NOISE_PALETTE` в `noise.rs` |
| Чувствительность к слабому движению | порог `0.05` в `core::compare(...)` в `main.rs` |

## ⚠️ Ограничения и известные особенности

* **Только macOS-бэкенд камеры**: жёстко задан `videoio::CAP_AVFOUNDATION`. На Linux замените на
  `videoio::CAP_V4L2` (или `CAP_ANY`), иначе камера не откроется.
* **Индекс камеры задан в коде** (`cam_index = 0`) — переключение на вторую камеру правится вручную.
* **Нет записи в файл**: программа только показывает результат; сохранение видео — не реализовано.
* **Эффект зависит от освещения**: в темноте оптический поток шумный, «проявляется» случайный шум.
* **Порог `0.05`** для неподвижности — компромисс: ниже него объекты «залипают», выше — шум на фоне.
* **Наследие видео-версии**: `src/frame_utils.rs` содержит копию констант из `config.rs` и функции
  `preprocess_frame`, `shift_texture`, `enforce_noise_rule`, которые сейчас не вызываются;
  в `config.rs` остались неиспользуемые `OUTPUT_SIZE`, `MAX_DURATION_SEC`, `MAX_FILE_SIZE`.
* **`minifb` требует GUI-окружения**: по SSH или внутри headless-контейнера окно не откроется.
